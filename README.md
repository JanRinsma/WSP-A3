For this assignment, I opted to use my own css rather than a 3rd party/bootstrap stylesheet. I referenced a number of sources during this project-mainly w3schools(https://www.w3schools.com/), but also MDN/mozilla developer network(https://developer.mozilla.org/en-US/), GeeksforGeeks(https://www.geeksforgeeks.org/), StackOverflow(https://stackoverflow.com/) as well as the code from lectures(mainly for layout/file structure info). I checked these sites for syntax refreshers on things I already knew, or refreshers on things I had forgotten- or for more theoretical reminders, rather than syntactical ones. For some of the sites I referenced, I looked at them, but did not use any info from them and eventually found an alternate solution on another site I referenced(most likely w3schools). While I looked at the code on these sites and used the methods/properties/etc. that I found there, I did not copy and paste anything-nevertheless, there is still some unavoidable overlap. It is also worth mentioning that I used express generator. To demo this site, "cd" into Assignment3/ExpressApp/assignment-3, open up a terminal, and type "npm start". Then, open up your web browser, go to the address bar, and type "localhost:3000". Or, use the cloud deployment link on canvas.
